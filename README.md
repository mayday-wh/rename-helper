# 重命名助手

一个用于批量重命名文件的 Windows 桌面小工具，使用 Python + Tkinter 编写，并使用 `uv` 管理项目。

当前版本：v1.2

## 主要功能

- 批量预览文件重命名结果，确认后再执行。
- 支持勾选部分文件，只重命名选中的项目。
- 支持包含子目录。
- 支持保存常用规则，下次可直接选择复用。
- 支持右键预览列表中的文件，打开文件或定位到所在目录。
- 自动保留原文件扩展名。
- 对目标重名、文件名为空、目标已存在等情况进行跳过提示。

## 运行方式

推荐直接运行：

```powershell
.\运行.bat
```

也可以使用 uv 手动运行：

```powershell
uv run --no-sync python main.py
```

基础自检：

```powershell
.\运行.bat --check
```

## 使用流程

1. 点击 `选择目录`，选择需要处理的文件夹。
2. 需要处理子目录时，打开 `包含子目录`。
3. 在左侧选择规则类别。
4. 填写规则名称、规则内容和对应参数。
5. 点击 `刷新预览` 查看新文件名。
6. 在右侧 `可选` 列勾选需要处理的文件。
7. 点击 `执行重命名`。

## 规则说明

### 删除词组

用于删除文件名中的指定内容。内容框通常是一行一个规则。

删除方式包括：

- `词组`：删除内容框中列出的固定词组。
- `从分隔符后删除`：从最后一个指定分隔符开始删除到末尾。
- `条件删除后缀`：格式为 `分隔符=>包含符号`，只有分隔符后包含指定符号时才删除后缀。
- `条件删除前缀`：格式为 `分隔符=>包含符号`，只有分隔符前包含指定符号时才删除前缀。
- `删除首尾数字段`：按分隔符删除开头和结尾的纯数字段。
- `删除括号内容`：清理 `[]`、`()`、`（）`、`【】`、`{}` 中的内容。
- `清理多余符号`：压缩重复的 `_`、`-`、空格、`.`、`·` 等符号。
- `删除首尾指定字符`：删除文件名开头和结尾的指定字符。

示例：

```text
_100_标题_999.mp4
删除首尾数字段，分隔符填 _
=> 标题.mp4
```

### 替换词组

用于把旧词替换成新词。

内容框可写：

```text
旧词=>新词
```

也可以一行一个旧词，并在 `统一替换为` 中填写统一的新内容。

### 固定位置添加

用于在文件名开头、结尾或指定索引位置添加文字。

### 名称加序号

按预览列表顺序重新生成编号。

- 名称填写 `图片`，分隔符 `_`，位数 `3`：生成 `图片_001`
- 名称留空，位数 `3`：生成 `001`

### 大小写转换

只转换文件名主体，不修改扩展名。

支持：

- 小写
- 大写
- 首字母大写
- 单词首字母大写

### 编号+1

只检测文件名主体末尾的编号，并将其加 1。

```text
image_009.png => image_010.png
image2026_final.png => 不变化
```

执行时会使用临时名中转，支持连续编号整体后移。

### 编号补零

将文件名开头的数字补齐到指定位数，便于按文件名排序。

```text
1.png   => 001.png
10.png  => 010.png
100.png => 100.png
```

## 保存规则

左侧可以填写 `规则名称`，然后点击 `保存规则`。

- 当前没有选中旧规则时：保存为新规则。
- 当前选中了旧规则时：保存会更新当前规则。
- 点击 `新建规则` 会取消当前选择，并清空规则名称和内容。

规则会保存到 `settings.json`。

源码运行时：

```text
项目目录/settings.json
```

打包后运行时：

```text
exe 所在目录/settings.json
```

## 打包方式

推荐使用项目自带脚本：

```powershell
.\打包.bat
```

打包配置自检：

```powershell
.\打包.bat --check
```

打包结果默认输出到：

```text
dist/RenameHelper_v1.2.exe
```
